# Math and quant learning path

## Priority 1 — Must know before real strategies

- Probability: expectation, variance, covariance, conditional probability.
- Statistics: sampling error, confidence intervals, hypothesis testing, multiple-testing risk.
- Returns: log returns, simple returns, volatility, drawdown.
- Backtesting: lookahead bias, survivorship bias, data snooping, transaction costs.
- Portfolio basics: diversification, correlation, exposure, position sizing.

## Priority 2 — Needed for robust research

- Time series: stationarity, autocorrelation, ARIMA intuition, regime shifts.
- Optimization: objective functions, constraints, overfitting, regularization.
- Risk metrics: VaR, CVaR, Sharpe, Sortino, Calmar, beta.
- Market microstructure: bid/ask spread, slippage, order books, liquidity, fees.

## Priority 3 — AI/ML layer

- Train/validation/test splits for time series.
- Cross-validation vs walk-forward validation.
- Feature engineering and leakage prevention.
- Calibration and uncertainty.
- Drift detection.
- Model registries and reproducibility.

## Priority 4 — Advanced research

- Stochastic processes.
- Bayesian methods.
- Convex optimization.
- Reinforcement learning.
- Execution algorithms.
- Market impact models.

## Suggested practice order

1. Implement buy-and-hold benchmark metrics.
2. Implement a simple moving-average strategy.
3. Add fees and slippage.
4. Add walk-forward testing.
5. Add risk sizing.
6. Only then add ML baselines.
